# Remote Troubleshooter

Ferramenta de diagnóstico e manutenção remota de servidores Linux, Proxmox VE e Dell iDRAC.

## Instalação

1. Abra a **[última versão](https://github.com/CarlosPavao/RemoteTroubleshooter-Releases/releases/latest)**.
2. Baixe o arquivo **`RemoteTroubleshooter-Setup-<versão>.exe`**.
3. Execute e siga o assistente — não precisa de senha de administrador.

Depois de instalado, o próprio aplicativo avisa e instala as novas versões pelo botão
**"Verificar atualizações"**.

Requisitos: Windows 10/11 64 bits.

---
Este repositório contém apenas os instaladores e o arquivo de atualização (`manifest.json`).
O código-fonte não é público.
